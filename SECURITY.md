# Security and Sensitive-Data Reporting

This repository contains only synthetic demonstration data. It must never be used as a storage location for protected health information (PHI), personally identifiable information, client exports, credentials, or production configuration.

## Report a concern

Do not open a public issue containing sensitive data. Contact the repository owner privately and provide only the minimum information required to identify the affected file or commit.

## Immediate containment

If sensitive material is discovered:

1. stop distribution and new clones;
2. remove public access where possible;
3. preserve incident evidence outside the public repository;
4. rotate exposed credentials;
5. purge the material from Git history using an approved history-rewrite process;
6. assess notification, contractual, and regulatory obligations;
7. document corrective controls before restoring publication.

The reference implementation is not a compliance certification and does not replace an organization's privacy, security, legal, or incident-response program.
