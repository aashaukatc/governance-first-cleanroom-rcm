# Governance-First Clean-Room RCM Architecture v0.1.1

First public research release of the governance-first clean-room reference architecture for healthcare revenue-cycle analytics.

## Included

- Design-science working paper and manuscript source
- Synthetic dirty and remediated RCM datasets
- Executable Python reference implementation
- SQL Server reference objects
- Mapping examples and report-family contracts
- QA-control matrix and data dictionary
- Architecture sources and generated diagram
- Reproducibility tests and release evidence
- ORCID-aware citation and Zenodo metadata

## Reproducibility result

- Dirty scenario: **RED** as designed
- Remediated scenario: **GREEN** as designed
- Synthetic clean records evaluated: **200 per scenario**
- Financial reconciliation exceptions: **0**

All data are synthetic, fictional, and non-PHI.
